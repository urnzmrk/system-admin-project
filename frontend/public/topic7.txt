# Topic 7 — LINUX USER ENVIRONMENTS: DESKTOPS, DISPLAY SERVERS & DISPLAY MANAGERS

## 1. From Command Line to Graphical Desktop
Linux can be used entirely from the command line, but desktop distributions also provide graphical environments. A Linux graphical session is built from several layers: a display server or display protocol, a display manager for graphical login, a desktop environment or window manager, and the applications used by the user.
Understanding these layers prevents a common misunderstanding: GNOME, KDE, Xorg, Wayland, and GDM are not different names for the same thing. They perform different roles in the graphical stack.
## 2. Display Servers: Xorg
Xorg, commonly called X or the X.Org Server, is the traditional open-source implementation of the X Window System used on Unix-like operating systems. It manages graphical display communication between applications and the screen environment.
Characterizes Xorg as mature and widely used but showing its age. This reflects its long history and broad compatibility.
## 3. Wayland
Wayland is a modern display protocol that defines communication between a display server and graphical clients. A server using Wayland is generally called a Wayland compositor because it also performs the composition of windows on the screen.
Contrasts Wayland with Xorg by describing it as newer and intended to improve the graphical architecture, while historically facing compatibility and feature-transition issues.
## 4. Display Managers
A display manager provides the graphical login screen and manages graphical user sessions. After a user enters a username and password, the display manager starts the appropriate display server/session and loads the selected desktop environment.
Lists LightDM, SDDM, and GDM. LightDM is designed to be lightweight and flexible, SDDM is used with X11 and Wayland environments, and GDM is the GNOME display manager.
## 5. What is a Desktop Environment?
A desktop environment is a collection of programs that provides a common graphical workspace. It normally includes panels, menus, system settings, file-management tools, themes, desktop controls, and other components that make the operating system easier to use without relying entirely on terminal commands.
The desktop environment as the control-center layer where users change display resolution, themes, colors, fonts, and similar settings.
## 6. Major Desktop Environments
Lists KDE Plasma, MATE, GNOME, Cinnamon, Budgie, LXQt, LXDE, XFCE, Deepin, Unity, Pantheon, Enlightenment, and several other environments. Each has a different balance of appearance, resource use, customization, and design philosophy.
XFCE and LXDE are associated with lightweight operation. KDE Plasma focuses on a feature-rich graphical environment. GNOME emphasizes a distinct desktop workflow and accessibility. MATE continues the traditional GNOME 2 style, while Cinnamon derives from GNOME 3 technologies while following a more traditional desktop metaphor.
## 7. Window Managers and i3
Not every graphical environment is a full desktop environment. i3 is a tiling window manager written in C and designed to arrange windows in non-overlapping layouts. A window manager can provide window placement and keyboard-driven control without including the complete collection of utilities normally supplied by a desktop environment.
This distinction is useful when discussing lightweight Linux setups and systems where users prefer to assemble their own graphical environment.

## 9. The Linux Graphical Stack
A Linux graphical desktop is built from several layers rather than one single program. The display system handles graphical output and input, a display manager may provide the login screen, and the desktop environment supplies panels, settings, windows, menus, and applications.
Understanding these layers helps administrators distinguish a login problem from a display-server problem or a desktop-environment problem.
## 10. X.Org / Xorg
Xorg is a free and open-source implementation of the X Window System display server. It has historically been the dominant graphical display system on Linux desktops.
Its long history gives it broad compatibility, although its architecture reflects design decisions made for older Unix workstations.
## 11. Wayland
Wayland is a display protocol intended to provide a more modern graphics architecture. A Wayland compositor performs roles that were traditionally divided among an X server, window manager, and compositor.
Modern desktop environments increasingly support Wayland while retaining X compatibility for older applications.
## 12. Display Managers
A display manager provides the graphical login screen and starts a user session after authentication. Common examples include GDM, SDDM, and LightDM.
The display manager is not the desktop environment itself; it is the component that helps start and manage graphical sessions.
## 13. GNOME
GNOME is a major Linux desktop environment focused on usability, accessibility, localization, and integration. It provides its own shell, settings applications, file manager, and session components.
GNOME is used as a default or major option by many distributions.
## 14. KDE Plasma
KDE Plasma provides a highly configurable graphical desktop and works closely with the Qt application framework. It is designed to be feature-rich while allowing extensive visual and behavioral customization.
KDE Plasma is presented as an easy-to-use environment with strong multimedia and desktop capabilities.
## 15. XFCE and LXDE
XFCE and LXDE are examples of desktop environments designed to use fewer system resources than heavier desktop environments. They can be suitable for older hardware, virtual machines, or users who prefer simpler interfaces.
LXQt developed from the merger of LXDE-related work and Razor-qt ideas.
## 16. MATE and Cinnamon
MATE continued the traditional GNOME 2 desktop model after GNOME 3 changed direction. Cinnamon originated from the GNOME 3 technology stack but preserves a more traditional desktop metaphor.
These projects show how Linux desktop communities can adapt existing technologies to different user-interface preferences.
## 17. Pantheon, Enlightenment and i3
Pantheon is associated with elementary OS and emphasizes a controlled, straightforward interface. Enlightenment is known for graphical effects and window-management features. i3 is a tiling window manager rather than a full traditional desktop environment.
These examples demonstrate that Linux user environments can range from complete integrated desktops to minimalist window managers.
## 18. Installing and Changing Desktop Environments
Linux distributions can often install additional desktop environments through the package manager. Examples include KDE Plasma, MATE, Cinnamon, XFCE, and Pantheon.
Installing multiple environments is possible, but administrators should understand that each may add many packages, services, and configuration files.
## 19. Key Takeaways
Linux graphical systems are made of several layers, not one single desktop program.
Xorg and Wayland are display-system technologies.
LightDM, SDDM and GDM manage graphical logins and sessions.
GNOME, KDE Plasma, XFCE, MATE, Cinnamon and others are desktop environments.
I3 is an example of a tiling window manager rather than a full traditional desktop environment.
Core Principle: The visible Linux desktop is built from multiple cooperating layers, not from a single graphical program.
