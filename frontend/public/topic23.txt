# Topic 23 — WEB SERVERS, APACHE, LAMP STACK & BASIC WEB APPLICATION HOSTING

## 1. What is a Web Server?
A web server provides content to web clients such as browsers. At the basic level, it loads files or generates responses and sends them across the network using HTTP or HTTPS. lists Apache, NGINX, LiteSpeed, Lighttpd, and other web-server software as examples.
Web servers are central to Internet and intranet applications, so administrators need to understand installation, firewall access, content directories, and related application components.
## 2. LAMP Stack
LAMP is an acronym for Linux, Apache, MySQL, and PHP. The stack combines the Linux operating system, Apache web server, MySQL database, and PHP processing to host dynamic web applications.
The components perform different jobs: Linux provides the operating platform, Apache handles HTTP requests, MySQL stores structured data, and PHP executes application logic that can generate dynamic page content.
Linux ↓Apache Web Server ↓PHP Application Logic ↓MySQL Database
## 3. Installing Apache
Demonstrates updating the package list, upgrading packages, and installing apache2 on Ubuntu. Once installed, Apache runs as a system service and must be allowed through the firewall if remote clients are expected to reach it.
After installation, administrators should verify the service status and test access from a browser or command-line client.
Sudo apt updatesudo apt upgradesudo apt install apache2
## 4. Apache Firewall Profiles
Ubuntu's UFW application profiles can open the ports needed by Apache. distinguishes Apache (port 80 only), Apache Full (ports 80 and 443), and Apache Secure (port 443 only).
Port 80 carries ordinary HTTP traffic, while port 443 is used for TLS/SSL-encrypted HTTPS traffic. Opening both ports is not automatically required; the firewall should match the intended deployment.
Sudo ufw app listsudo ufw allow in "Apache"sudo ufw status
## 5. Installing MySQL
The database component can be installed with the mysql-server package. also shows mysql_secure_installation and phpMyAdmin as related administration tools.
MySQL provides persistent application data, but it should be secured separately from the web server through account permissions, network restrictions, and database configuration.
Sudo apt install mysql-serversudo mysql_secure_installationsudo apt install phpmyadmin
## 6. Installing PHP
PHP provides server-side application processing in the LAMP model. installs PHP together with the Apache PHP module and the PHP-to-MySQL connector.
This allows Apache to execute PHP content and allows PHP code to communicate with MySQL.
Sudo apt install php libapache2-mod-php php-mysql
## 7. Creating a Web Application Directory
Creates a directory under /var/www for a test application and then accesses it using the server's IP address. /var/www is a common web-content location on Debian/Ubuntu Apache systems.
In a real deployment, administrators must also manage file ownership, permissions, virtual-host configuration, TLS certificates, and application security.
Sudo mkdir /var/www/test_app/ # Example test URLhttp://IP_address/test_app
## 8. Testing and Troubleshooting the Web Stack
When a web application does not load, troubleshooting should be layered: confirm the server is reachable, verify Apache is running, verify the firewall, confirm the correct document root, check Apache logs, confirm PHP is installed, and then test database connectivity if the page depends on MySQL.
This layered approach prevents administrators from changing unrelated settings while the real problem is somewhere else in the stack.
## 9. What a Web Server Does
A web server listens for HTTP or HTTPS requests and responds with web content. Static content may be read directly from files, while dynamic content may be generated by application code.
Web-server administration therefore combines network configuration, files, permissions, security, and application integration.
## 10. The LAMP Stack
LAMP represents Linux, Apache, MySQL, and PHP. Together these components provide an operating system, web server, database, and server-side programming environment for dynamic websites.
The stack is a classic example of combining open-source components into a complete application platform.
## 11. Installing Apache
On Ubuntu, Apache can be installed with APT after updating package information.
After installation, administrators should confirm service status, firewall access, and the page being served.
## 12. Apache Service and Files
Apache runs as a system service and reads configuration files that define listening ports, modules, virtual hosts, and document locations.
Administrators should understand both service control and file permissions because the web server must be able to read the content it serves.
## 13. UFW Application Profiles
Ubuntu's UFW firewall can provide application profiles such as `Apache`, `Apache Full`, and `Apache Secure`.
These profiles correspond to opening port 80, ports 80 and 443, or only port 443.
## 14. HTTP Port 80
Port 80 is the conventional TCP port for unencrypted HTTP. Traffic can be read in transit unless additional protection is provided.
Modern public websites commonly redirect HTTP users to encrypted HTTPS.
## 15. HTTPS Port 443
Port 443 is the conventional TCP port for HTTPS, which protects web traffic with TLS.
Opening the firewall port is only one part of HTTPS; the web server must also be configured with valid certificates and TLS settings.
## 16. Installing MySQL
The LAMP sequence includes installing a MySQL-compatible database server and running security-oriented initialization steps.
The database stores application data that dynamic web applications can query and update.
## 17. Installing PHP
PHP provides server-side application logic and can be integrated with Apache and MySQL-related libraries.
When a browser requests a PHP page, the server processes the code and returns generated output rather than exposing the PHP source directly.
## 18. Virtual Hosts
Virtual hosts allow one Apache installation to serve multiple sites or applications based on hostnames, addresses, or configuration rules.
A simple website directory under `/var/www/` can illustrate application hosting.
## 19. Testing a Web Server
Testing should confirm that the service is running, the firewall permits the desired port, the correct content is served, and the site is reachable from the intended client.
Troubleshooting may also involve DNS, file permissions, virtual-host configuration, logs, and application errors.
## 20. Key Takeaways
A web server responds to HTTP/HTTPS requests from clients.
LAMP combines Linux, Apache, MySQL, and PHP for dynamic web hosting.
Apache installation must be paired with correct service and firewall configuration.
PHP and MySQL add application processing and persistent data storage.
Troubleshooting should move through network, service, firewall, application, and database layers.
Core Principle: A web platform is a stack of cooperating network, server, application, database, filesystem, and security components.
